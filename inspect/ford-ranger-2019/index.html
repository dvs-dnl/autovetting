2019 Ford Ranger
XL / XLT / Lariat (T6 platform, US 2019-2023)
Watchful

The T6 Ranger returned to North America after an 8-year absence and brought the excellent 2.3L EcoBoost with it. First-year (2019) quality issues existed but were resolved in 2020+. The 10-speed automatic received TSB updates for hesitation and shudder. Cam phaser noise on cold start is reported on some early examples — the same family issue as the F-150 EcoBoost. Strong mid-size truck value when first-year issues are addressed.

Cam phaser rattle on cold start is reported on Ranger EcoBoost above 60k miles — same engine family as F-150 EcoBoost.

10-speed transmission shudder / TSB

High Attention
The 10R80 in the Ranger received multiple TSBs for shudder at 25–45 mph and hesitation under light throttle.
Test extensively at light throttle 25–45 mph for any shudder.
Est. cost: $350–$550 fluid + calibration / $4,500+ transmission Source: Ford TSB 19-2200

What the VIN tells you

The 2019 Ranger has exactly one engine, so the 8th VIN digit confirms rather than chooses — verified against NHTSA vPIC by changing that one character and nothing else off 1FTER4FH*KLA00000: ‘H’ returns Ranger / 2.3L / gasoline, while ‘A’, ‘B’ and ‘J’ fall off the 2019 pattern entirely (error 14, or a fallback into Ford’s 1989 truck table with multiple matches). Every US T6 Ranger of this year is the 2.3L EcoBoost with the 10-speed, so the 10-speed shudder TSB and the cam-phaser cold-start check below apply to every example — there is no safer engine to shop for. The decode that does change what you are buying is drivetrain, and it sits in position 7, not position 6: holding the rest constant, ‘F’ returns 4WD/4x4 and ‘E’ returns 4x2 (1FTER4FH and 1FTER1FH both decode 4WD; 1FTER4EH and 1FTER1EH both decode 4x2), so the ‘1’-versus-‘4’ character is not the drivetrain. Confirm that before paying a 4x4 premium — FX4 badging and 4x4 hardware are not the same thing. One limit worth knowing: vPIC returns no engine model, cylinder count or horsepower on this VIN pattern at all, so the decode will not confirm the transmission, the FX4 off-road package or the tow package; read those off the door-jamb label or a window-sticker lookup instead.
