2018 Volkswagen Tiguan
S / SE / SEL / SEL Premium R-Line (MQB, 2nd gen, 2018-2024)
Watchful

The 2nd-gen Tiguan (2018+) on the MQB platform is a substantial improvement over the 1st gen. The EA888 2.0T is the same family as Audi's engine but with different tuning. GDI carbon buildup on intake valves is a long-term service item. The 8-speed automatic is the Aisin 09P torque-converter unit, not a DSG, so there is no dual-clutch pack on a US-market car. Strong compact SUV value for buyers who maintain the service schedule.

09P 8-speed automatic — hesitation and fluid history

High Attention
US cars use the Aisin AW 09P torque-converter automatic, not a DSG, so there is no clutch pack or mechatronic unit. The documented 2018–2020 complaint is low-speed hesitation and harsh shifting, addressed by TCM software rather than hardware.
Test stop-and-go under 15 mph for hesitation or a harsh 1-2 shift, then ask whether the TCM software update was performed.
Est. cost: $0 TCM software / $250–$450 ATF service (G 055 540 A2) Source: VW Self Study Program 850193 (09P / AQ 450, Aisin AW)

What the VIN tells you

On the MQB Tiguan the 8th VIN digit is the engine position and it has exactly one legal value, so it forks nothing: every US 2018 Tiguan is the 2.0L TSI EA888 at 184 hp. Single-variable decodes at vpic.nhtsa.dot.gov for model year 2018 on the '3VV2B7A' base: position 8 = 'X' returns Tiguan, 2.0L, 4-cylinder, 184 hp, 8-speed automatic, while 'C', 'W' and 'Y' all return no data. What does move is position 4, and it is the drivetrain. '3VV1B7AX' returns Trim S with DriveType FWD; '3VV2B7AX' returns 'SE, 4Motion SEL' with DriveType AWD; '3VV3B7AX' returns 'SE, SEL' with DriveType FWD - and a full decode of a real car agrees, 3VV3B7AX9JM000932 returning ErrorCode 0, Tiguan, 184 hp, 8-speed automatic, FWD, built at Puebla. The 4MOTION Haldex coupling service below therefore applies only to a position 4 = '2' car; read the drivetrain from position 4, never from the 8th digit. The transmission is where this entry was wrong, and it is worth saying plainly: a US-market 2018 Tiguan has no DSG. It uses the 09P 8-speed, an Aisin AW torque-converter automatic. Volkswagen's own Self Study Program 850193 gives the code as AQ 450 and the manufacturer as AISIN AW CO., LTD. Japan, and describes a torque converter acting as a fluid coupling with an ATF pump and planetary gearsets, filled with 7.65 L of G 055 540 A2; Blauparts and PartsAdvisory both identify the 2018-2024 Tiguan 8-speed as the same 09P torque-converter unit. There is no dual-clutch pack to replace and no mechatronic unit to fail, so a quoted DSG clutch-pack repair on this car is not a real line item. The documented 2018-2020 complaint against this transmission is low-speed hesitation and harsh shifting addressed by TCM software - test for that, and ask for the software history.
