The QX80 is a Nissan Patrol-based full-size luxury SUV — the same 5.6L VK56 V8 as the Titan and Armada but in a more premium package. Excellent reliability and extremely durable drivetrain. Main checks: the hydraulic body-motion-control and air-suspension hardware, transmission fluid service and records — not the Takata airbag recall, whose QX80 scope ends with the 2014 model year. Great value vs. Lexus LX or Mercedes GLS at similar mileage.

Open recalls — VIN check (Takata scope ends at 2014)

There is exactly one Takata-supplied campaign in this family, from October 2014, and it covers the 2013 QX56 built 1 September 2012 to 26 April 2013 plus the 2014 QX80 built 18 June 2013 to 11 February 2014 — roughly 1,900 vehicles whose driver inflator was assembled with an incorrect internal part. That is a build defect, not the propellant-degradation recall everyone means by "the Takata recall," and a 2018 QX80 is four model years outside it.
Run the VIN at nhtsa.gov/recalls and require every genuinely open campaign closed before purchase.

What the VIN tells you

Only one engine here, so there is no powertrain fork to decode: every 2018 QX80 is the 5.6L VK56VD DOHC V8 (400hp) paired with a 7-speed automatic — the same bulletproof V8 shared with the Nissan Armada and Titan, with no cylinder deactivation. The VIN engine character is 'A' (VK56VD). What the VIN and trim actually change: 2WD versus Nissan's All-Mode 4WD, and whether the truck carries the Hydraulic Body Motion Control suspension and 22-inch wheel package (ProACTIV/Sensory/Autograph) — that hydraulic system and the air-suspension components are the real cost items to inspect. The Takata inflator campaign in this family covers only the 2013 QX56 and the 2014 QX80, so a 2018 sits four model years outside it. Don't confuse this Z62 with the 2025 redesign, which switched to a twin-turbo V6.
