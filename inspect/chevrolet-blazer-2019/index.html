2019 Chevrolet Blazer
L / 2LT / 3LT / RS / Premier (2nd gen, 2019–2023)
Monitor

The reborn Blazer is a sharp-looking mid-size crossover but first-year quality was inconsistent. For 2019 the choice is the 2.5L four or the 3.6L V6 — the 2.0T that shows up in a lot of Blazer buying guides was not offered until 2020, so ignore 2.0T-specific advice when shopping a 2019. The V6 is the one to have. The main concerns are 9-speed automatic rough shifts, infotainment glitches, and first-year build variance. Prefer 2021+ with the V6 if you can stretch.

Powertrain

2.0T oil consumption (LTG engine) — 2020+ cars only

High Risk
The 2.0T LTG engine in the Blazer had documented oil consumption complaints — some owners report 1 qt per 2,000–3,000 miles. GM did not issue a recall.
Check dipstick immediately. Ask owner how often they add oil.
Est. cost: $0–$2,500 Source: NHTSA complaints / GM TSBs

9-speed automatic rough shifts (both engines)

Monitor
The GM 9T65 9-speed automatic is prone to harsh shifts, shuddering, and hunting between gears. Software updates help but don't fully resolve all cases.
Test all city and highway throttle scenarios. Any shudder or harsh kick = request TSB update history.
Est. cost: $0 software update; $3,000+ if transmission hardware needed Source: GM 9-speed pattern

3.6L V6 (LGX) — more reliable choice

Low Risk
The 3.6L LGX V6 in the Premier trim is significantly more reliable than the 2.0T. No widespread failure modes.
Standard oil check and cold-start idle. Smooth delivery expected.
Est. cost: Routine maintenance Source: GM LGX reliability history

Infotainment glitches

Monitor
Early Blazers had Chevrolet Infotainment 3 freezing and CarPlay connectivity issues. Software updates resolve most.
Test full CarPlay/Android Auto pairing. Reboot infotainment and verify quick restart.
Est. cost: $0 update Source: GM infotainment TSBs

Recall

Front brake hose recall (select 2019–2020)

High Risk
Some 2019–2020 Blazers were recalled for front brake hoses that could chafe and develop fluid leaks.
Run VIN at nhtsa.gov/recalls.
Est. cost: Free dealer repair Source: NHTSA recall

On the 2.0T engine, oil change frequency is the key predictor of oil consumption severity.
Request all records. 2.0T with no records = risk premium.

What the VIN tells you

On the second-generation Blazer the 8th digit is the engine character and it resolves cleanly, which makes a 2019 easy to shop once you know only two engines exist — verified against NHTSA vPIC by varying that one character off 3GNKBCRS1KS000000 and holding the rest constant: S returns Chevrolet / Blazer / 2019 / 3.6L / 6 cylinders / EngineModel LGX / V-shaped; A returns 2.5L / 4 cylinders / EngineModel LCV / in-line; X returns error 14 with every engine field blank. So the digit is a two-way fork, LCV four or LGX V6, and the 2.0T LTG this checklist flags as a 2020-and-later engine does not appear on any 2019 pattern tested — the measured version of the warning in the entry above. Drivetrain and trim ride together at position 6, not at 8: C returns 2LT with FWD, H returns 3LT with AWD, and K returns Premier with AWD on an error 0 clean decode. That matters because AWD was optional and a badge is the easiest thing on the car to change. One decoder artifact recorded on purpose, because a reader who checks will otherwise think the note is sloppy: 3GNKBKRA1KS000000 — Premier, AWD, carrying the 2.5L character — decodes without complaint, even though the 2.5L was never paired with AWD or with Premier trim. vPIC reads GM's engine table without validating the combination, the same artifact the Gladiator and Ram notes documented, so a decode returning a configuration is evidence of what the VIN encodes, not proof the car was built that way. Confirm the V6 at the car: badge, and coil count, six versus four.
