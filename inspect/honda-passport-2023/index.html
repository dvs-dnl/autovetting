What the VIN tells you

2nd-gen Passport (2022+) has a single powertrain: the 3.5L SOHC i-VTEC V6 (J35Y6, 280 hp) with the 9-speed automatic, no hybrid and no VCM cylinder deactivation, so there is no engine fork to decode. Honda encodes powertrain across VDS positions 4-8 and the 8th digit reads trim rather than a clean engine letter, so confirm the build via vPIC rather than one character. 10th digit P = 2023 (N = 2022, R = 2024).
