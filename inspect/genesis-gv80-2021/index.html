What the VIN tells you

The first-gen GV80 (JX1) offers two engines, and the 8th VIN digit tells them apart: B = the 2.5T turbocharged inline-four (300 hp), C = the 3.5T twin-turbo V6 (375 hp) — on U.S. cars the 5th VIN digit mirrors it (B for the four, C for the V6). The twin-turbo V6 is the preferred, more desirable powertrain; both use an 8-speed automatic and both were sold in rear- and all-wheel drive. No chronic engine-family failure changes the inspection between the two, so the decode matters mainly for confirming you are paying for the engine advertised. Confirm the full spec at autovetting.com/decode or vpic.nhtsa.dot.gov, and run the VIN at nhtsa.gov/recalls before purchase.
